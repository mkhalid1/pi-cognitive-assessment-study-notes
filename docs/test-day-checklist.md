# Test-day checklist

A short list for the day you sit the PI Cognitive Assessment. Most of it is about protecting 12 minutes of full attention.

## When the invitation arrives

- [ ] Note the deadline in the email and plan a time well before it.
- [ ] Check whether the email includes a link to PI's official sample questions. If it does, plan to do them first.
- [ ] If you need an accommodation, such as extra time, tell the employer **now**, before you open the test. PI offers 18-minute and 24-minute versions.
- [ ] If English is not your strongest language, ask whether the test is available in another one.

## The day before

- [ ] Do one short timed set, not a full study session.
- [ ] Reread the traps lists for your weakest area.
- [ ] Sleep. A speed test punishes tiredness more than almost anything else.

## One hour before

- [ ] Choose a quiet room and a time when you will not be interrupted for 20 minutes.
- [ ] Use a computer with a stable internet connection. Close other tabs, apps and notifications.
- [ ] Have scrap paper and a pen ready, if the instructions allow them. PI's public pages do not say either way, so check the on-screen instructions.
- [ ] Have a glass of water and use the bathroom.

## In the first minute

- [ ] Read the instructions properly. They are not timed in the same way as the questions.
- [ ] Note the start time so you can pace yourself against the checkpoints in the [timing guide](timing.md#a-pacing-plan-for-12-minutes).
- [ ] Stay on the test window. PI says the test blurs the screen and blocks copy and paste if you navigate away.

## During the test

- [ ] Read the question line before the details.
- [ ] Use the 20-second rule: if you are stuck, guess and move on.
- [ ] Never leave a blank. PI scores only correct answers, so a guess cannot lose you anything.
- [ ] Do not panic if you do not reach question 50. Fifty questions in 12 minutes is a tight limit by design, and your score is the number you get right, not how far you get.
- [ ] In the last 30 seconds, answer anything left on screen.

## Afterwards

- [ ] Do not expect to see a score. PI recommends employers keep scores confidential and talk about fit instead.
- [ ] If you have the PI Behavioral Assessment as well, take a short break first. See [taking both assessments](with-the-behavioral-assessment.md).
- [ ] Write down which question styles felt hardest. If you are applying to other roles that use PI, that list is your study plan.

## Last practice before the real one

Run one full 50-question, 12-minute set a day or two before, not on the morning itself: the [free PI Cognitive practice test on PrepClubs](https://prepclubs.com/free-practice-tests/pi-cognitive-assessment?utm_source=github&utm_medium=referral&utm_campaign=ngp6xf&utm_content=pi-cognitive-assessment).
