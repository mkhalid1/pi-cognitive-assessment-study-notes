# If you are also taking the PI Behavioral Assessment

Most people who get a PI Cognitive Assessment link get a second one too: the PI Behavioral Assessment. PI recommends pairing them, so that an employer can see both how well someone is likely to handle a role's complexity and how they are likely to behave at work. The two are very different, and the way you prepare for each is different too.

## The two side by side

| | PI Cognitive Assessment | PI Behavioral Assessment |
|---|---|---|
| What it measures | General cognitive ability: how fast you are likely to learn | Four workplace drives: dominance, extraversion, patience, formality |
| Format | 50 multiple-choice questions | Two lists of adjectives: tick the ones that apply |
| Time | 12 minutes, timed | Untimed, about six minutes on average |
| Right answers? | Yes | No. PI says it is not pass or fail and has no right or wrong answers. |
| Compared with | A cognitive target set for the job | A behavioural target set for the job |
| Used after hiring? | PI says no: it is not a development tool | Yes, for coaching and team development |

## Which to do first

If the order is up to you, do the **behavioural assessment first**. It is untimed and low pressure, which makes it a gentle start. Then take a short break and do the cognitive test when you are fresh. The cognitive test is the one that rewards being alert.

If the employer has set the order, follow it. Neither result depends on the other.

## How to prepare for each

**For the cognitive test,** practice genuinely helps: learning the question styles and the pace removes the shock of the first few minutes. That is what most of this repo is for. Start with the [diagnostic](diagnostic.md).

**For the behavioural assessment,** the best preparation is understanding how it works, then answering honestly. It asks you twice to pick adjectives: once for how others expect you to act at work, and once for how you really are. PI says it is built so that people cannot map individual words to the factors, and that scores are read within the person rather than against other people. Trying to "game" it tends to produce a muddled profile rather than an impressive one.

A few practical points from PI's own guidance on the behavioural assessment:

- There is no maximum number of words you can tick. PI says results need at least six words in each list to be valid, and that very large selections are not interpretable either. Tick the words that genuinely fit.
- You can take it on a computer, tablet or phone. PI says the device makes no difference to the results.
- PI recommends people take it no more than once a year, so you will usually only do it once for a given employer.

For a full guide to the behavioural side, including worked examples of how the two lists work, see the companion repo, [PI Behavioral Assessment Study Notes](https://github.com/mkhalid1/pi-behavioral-assessment-study-notes). To see how the adjective lists feel before the real thing, try the [free PI Behavioral practice profile on PrepClubs](https://prepclubs.com/free-practice-tests/pi-behavioral-assessment/practice-profile?utm_source=github&utm_medium=referral&utm_campaign=ngp6xf&utm_content=pi-cognitive-assessment).

## What the employer sees

Both results are compared with targets the employer set for the job, and PI tells employers to use them alongside interviews and your experience, not as the only input. A strong cognitive score does not make up for a poor interview, and a behavioural profile that differs from the target is not a fail. It is a prompt for questions in the interview, and PI's software produces interview questions for exactly that purpose.
