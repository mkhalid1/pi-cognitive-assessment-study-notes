# Glossary

Terms you will meet in PI's materials, in your invitation or in these notes.

| Term | Meaning |
|---|---|
| **Abstract reasoning** | One of the three content areas: solving pattern problems made of shapes and symbols. See the [abstract guide](sections/abstract-reasoning.md). |
| **Accommodation** | A change to how the test is given, for a candidate with a disability. For the PI Cognitive Assessment, the main one is extra time (18 or 24 minutes). |
| **Analogy** | A question of the form "A is to B as C is to ?", using words or shapes. |
| **CA** | PI's own short name for the Cognitive Assessment. |
| **Criterion-referenced** | PI's description of the test: the score is based on your own number of correct answers, rather than a ranking against others taking it at the same time. |
| **Equating** | A statistical method that puts different versions of a test on the same scale. PI uses it so standard and extended-time scores can be compared fairly. |
| **General cognitive ability** | The broad ability to learn, reason and solve problems. It is what PI says the test measures as a single trait. |
| **Item** | One question. |
| **Item pool** | The larger set of questions from which each candidate's 50 are drawn. |
| **Job Assessment** | A PI tool employers use to describe what a role needs and set the job targets. Candidates do not take it. |
| **Job target** | The cognitive score an employer sets for a particular role. |
| **LOFT** | Linear-on-the-fly testing. PI's engine for building an equivalent but different set of questions for each test session. |
| **Match score** | How close your scaled score is to the job target. PI gives a 10 for a score at or above the target, and less on a sliding scale below it. |
| **Norm** | A reference distribution of scores. PI says the general population average on its scale is 250. |
| **Numerical reasoning** | One of the three content areas: number series, percentages, ratios and short word problems. See the [numerical guide](sections/numerical-reasoning.md). |
| **PI** | The Predictive Index, the company that publishes the test. |
| **PI Behavioral Assessment** | PI's untimed adjective checklist about workplace drives, often sent with the cognitive test. See [taking both assessments](with-the-behavioral-assessment.md). |
| **Raw score** | The number of correct answers. PI says raw scores should not be used for decisions; the scaled score should. |
| **Sample questions** | PI's official practice set, which employers can include in the invitation. Not part of the real item pool and not scored. |
| **Scaled score** | Your reported score, from 100 to 450. The only score PI says is meant for hiring decisions. |
| **Sub-scores** | Correct answers in each of the verbal, numerical and abstract areas. PI says they are not valid for decisions. |
| **Verbal reasoning** | One of the three content areas: word relationships, meanings and short statement logic. See the [verbal guide](sections/verbal-reasoning.md). |
